- `node --check web-agent/app.js` 通过。

离线测试使用模拟模型响应，不作为在线模型效果证明。

### 验证中发现并修复的问题

首轮模型将“授权已过期”误判为“已证实没有当前代理关系”。实际含义应为当前关系未知。增加独立证据验收后，完整回归得到表中结果；同时把这条边界补入专家修订的方法。

这说明验收机制在该样例中有效，不表示独立模型验收器不会再次犯错。样本量小，未做统计显著性评估。

## 3. 公开网页验证

使用公开 Microsoft / LinkedIn 案例，实际执行搜索、访问官方页面、读取收购历史表，并保存可核对来源。

- 搜索过程中出现未返回可读取结果、失效公告 URL、SEC 自动化访问限制；首次达到轮次上限，没有完成草稿。
- 通过追加指令收敛到已取得的微软官方 Acquisition History 来源，发现不换行空格导致引用匹配失败。
- 只规范空白差异后保留原文；再次补充时效边界，成功提交三个维度均未知的草稿，并说明历史收购事实与当前证据缺口。

因此这次证明了真实网页访问、受阻留痕、专家纠正与继续查证；**没有证明无人干预的开放网络核验稳定成功**。正式使用仍需可靠资料源、来源适配与更完整评测。

## 4. 界面验证

通过实际浏览器操作验证：

- 原文引文点击、选择文本、补充解释、记录保存。
- 专家手动打开资料页，点击共享浏览器截图中的真实链接。
- 修改候选 Skill，保存 v2，确认启用并为新案例选择 v2。
- 真实运行期间暂停并接管，手动补查，再继续 Agent。
- 页面刷新恢复对话、来源、标签和方法。

界面创建的 v2 新案例在暂停、专家补查、恢复后得到三个维度未知，并已通过界面确认；[验证摘要](../examples/agent/ui-validation.json)。
