# Linkdesk 产品说明

## 产品目标

帮助关系数据团队在专家资源有限时，将候选关系转化为可追溯的标注，并复用已经验证过的检查方法。

## 三个决策

1. **专家先看什么。** 材料冲突和可能连接多个主体的关系先核验；相似模式先选代表；从其余案例保留随机抽检，避免只处理容易案例。
2. **每案确认什么。** 集团、代理和预算分别依靠适用证据。共享操作是线索；来源可靠不等于能证明任意结论。未知可以保留。
3. **专家经验怎样复用。** 来源必须已复核。模板先通过固定边界回归，再对每案检查条件，生成引用本案证据的草稿。最终标签仍由人工确认。

## 相比单案审核界面的增量

| 问题 | 机制 | 需要验证的效果 |
|---|---|---|
| 有限专家无法均匀覆盖全部候选 | 明确排序、代表去重、随机抽检 | 高影响问题覆盖与抽检发现率 |
| 同类问题重复阅读、组织理由 | 分组对比、从复核记录沉淀检查模板 | 整理与解释耗时 |
| 经验复用容易过度泛化 | 本案授权校验、控制关系反例排除、应用预览 | 错误套用率 |
| 证据和判断随时间变化 | 指纹、引用、规则版本、失效和撤回 | 过期依据被继续使用的比例 |

这些是产品假设，不代表已测得的业务提升，也不假设任何既有平台缺少同类能力。

## 排序口径

当前顺序：材料冲突 → 候选边涉及至少 8 个主体 → 有有效代理授权的操作重合模式代表 → 有直接控制证明的常规复核 → 先补证。相同优先级按案例 ID 稳定排序。

“8 个主体”是演示用可解释阈值，未进行成本标定。未来应结合错误关联的实际影响、专家耗时与地区差异校准。图谱影响规模来自样例中的关联主体集合，不是交易额。

每轮至少 1 个随机抽检位，抽自未被优先选中的候选。随机种子随计划保存。本版本不做按地区的分层概率抽样或总体误差估计。

## 明确不做的推断

- 代理关系不能证明两家公司不属于同一集团；代理与集团关系可以同时成立。
- 相同股东、IP、联系人、App 不能单独确定共同控制。
- 同一集团不能自动推导统一广告预算。
- 一个案例的复核通过不能成为另一个案例的事实证据。
- 合成回归全通过不能代替线上准确率与专家耗时对照实验。

## 人机分工

模型可参与正文提取、建议归因和表达；规则负责材料有效性、版本与复用边界；业务人员负责核实材料来源与最终关系判断。本地版本使用保守规则提取，在线模型适配器尚未完成真实服务验证。

## 试点设计

先统一关系类型、适用时点与验收标准。将难度匹配的样本随机分配给新旧流程，记录整理、补证、初标、复核与返工的时间，独立抽检最终标签。按地区、材料完整度和关系类型分层报告。

比较单位合格标签的总人工时间与专家时间，同时报告确认覆盖率、保留未知比例和错误关联。若只降低专家耗时却把更多工作转移给标注人员，应计入总成本。
