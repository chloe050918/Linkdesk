# Agent 实际执行产物

这些文件来自 2026-11-10 的真实方舟模型与 Playwright 浏览器验收，输入是合成公司和合成网页。专家角色操作由工程验收流程模拟。

- `live-validation.json`：四案完整链路摘要，含实际会话 ID、工具/模型调用计数和生成的方法。
- `agency-trace.json`：查证、纠正、确认与方法提炼过程。
- `transfer-trace.json`：应用方法到新公司，使用新公司的来源。
- `expired-trace.json`：过期授权保留当前关系未知。
- `conflict-trace.json`：集团控制与代理关系同时存在。
- `SKILL.md` / `skill-v2.json`：界面中直接编辑并启用的 v2 方法；v1 仍保留用于追溯。

原始网页快照保存在案例自己的记录中。文件中的 localhost 链接用于本地样例，GitHub 不提供该服务。新建核验时会根据当前服务器地址生成自己的资料链接。

这些文件证明执行发生过，不是生产准确率或业务收益报告。
